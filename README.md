# Análisis Exploratorio y Visualización de Datos con SQL y NoSQL

## Descripción

Este proyecto presenta un análisis exploratorio y visualización de datos utilizando diferentes tecnologías de bases de datos **SQL y NoSQL**, con el objetivo de demostrar cómo pueden ser utilizadas para la extracción, transformación, análisis e interpretación de información proveniente de diferentes fuentes.

El proyecto integra tres escenarios principales:

* **Oracle HR:** análisis de datos estructurados utilizando Oracle SQL.
* **SQL Server Northwind:** exploración y análisis de información empresarial mediante consultas SQL.
* **MongoDB – Sensores:** procesamiento y análisis de datos provenientes de sensores utilizando una base de datos NoSQL orientada a documentos.

A través de estos escenarios se aplican técnicas de **Exploratory Data Analysis (EDA)** para identificar patrones, tendencias, relaciones, distribuciones, valores atípicos y características relevantes de los datos.

## Objetivos

* Explorar datos almacenados en bases de datos relacionales y NoSQL.
* Utilizar consultas SQL para obtener y transformar información.
* Trabajar con datos almacenados en MongoDB.
* Aplicar técnicas de análisis exploratorio de datos.
* Identificar patrones y relaciones relevantes en los datasets.
* Generar visualizaciones que faciliten la interpretación de los resultados.
* Comparar diferentes enfoques de almacenamiento y consulta de datos.
* Demostrar la aplicación práctica de tecnologías de **Big Data y Data Analytics**.

## Metodología

El análisis sigue un flujo general de trabajo compuesto por:

```text
Fuentes de datos
       ↓
Bases de datos SQL / NoSQL
       ↓
Extracción de información
       ↓
Limpieza y transformación
       ↓
Análisis exploratorio (EDA)
       ↓
Visualización
       ↓
Interpretación de resultados
```

El proyecto busca demostrar que la elección entre tecnologías relacionales y NoSQL depende de las características de los datos, los patrones de consulta y los objetivos del análisis.

## Resultado esperado

Como resultado, se obtiene una visión exploratoria de diferentes conjuntos de datos y se generan visualizaciones que permiten comprender mejor su comportamiento y extraer información relevante para el proceso de toma de decisiones.

Este proyecto forma parte de un trabajo académico orientado al estudio de **Big Data, bases de datos, análisis exploratorio y visualización de información**.
